# KnitLog

KnitLog is a web application for managing and tracking personal
knitting projects.

## About

KnitLog helps users organize their knitting projects and keep track
of project progress, status, and notes in one place.

This project is developed as part of the Evolusi Perangkat Lunak
course and will be continuously evolved throughout the semester.

## Features

- Create knitting projects
- View project list
- Update project information
- Delete projects
- Track project status and progress
